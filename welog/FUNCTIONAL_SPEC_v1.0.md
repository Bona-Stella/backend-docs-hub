# 🏥 WeLog (위로그) - V1.0 기능 명세서

> **WeLog**는 '위(Stomach)'와 '로그(Log)'를 합친 이름으로, 식습관 기록과 질병 발병 데이터를 분석하여  
> 오늘과 내일의 발병 확률을 예측해 주는 **위장 건강 관리 헬스케어 서비스**입니다.

---

## 1. 👤 회원가입 및 온보딩 (User Onboarding)
사용자의 진입 장벽을 낮추면서도, 서비스 이용에 필수적인 '건강 데이터'를 자연스럽게 수집하는 것이 목표입니다.

| 기능 구분 | 구현 목표 및 상세 내용 | 주요 UI/UX 스펙 | 비고 |
| :--- | :--- | :--- | :--- |
| **스플래시** | **브랜드 아이덴티티 전달**<br>- 앱 실행 시 로고 노출 및 초기 데이터 로딩 처리.<br>- 자동 로그인 여부 체크 후 화면 분기. | • `WELOG` 타이포 + 네온 로고<br>• 애니메이션: Fade In/Out | |
| **회원가입** | **단계별 입력 (Step-by-Step)**<br>- **Step 1 (계정):** 이메일/비밀번호 유효성 실시간 검증.<br>- **Step 2 (프로필):** 닉네임 설정 및 관리 질병 등록.<br>- **완료:** 이메일 인증 안내 모달 팝업. | • **유효성 시각화:** 충족 시 녹색 테두리 + 체크(✔) 아이콘<br>• **비밀번호:** 8자 이상, 특수문자 포함 조건 체크 UI | |
| **로그인** | **다양한 인증 방식 지원**<br>- 이메일/비밀번호 기반 로그인.<br>- **Google OAuth2** 소셜 로그인 지원.<br>- 비밀번호 표시/숨기기(Show/Hide) 토글 기능.<br>- **이메일 인증** 및 **비밀번호 재설정** 기능. | • 입력 필드 내 `👁️` 아이콘 제공<br>• Google 로그인 버튼 제공<br>• 오류 시 Toast 메시지 출력 | Resend 이메일 서비스 연동 완료 |
| **초기 설정** | **개인화 데이터 수집 (질병)**<br>- 관리할 질병을 **태그(Chip)** 형태로 다중 선택.<br>- 목록에 없는 질병은 '직접 입력'으로 추가. | • **질병 칩:** 선택/미선택 상태 색상 반전<br>• **추가 버튼:** `[+ 추가]` 클릭 시 입력창 활성화 | 최소 1개 필수 선택 |

## 2. 🏠 메인 대시보드 (Dashboard)
사용자의 현재 위장 상태(종합 위험도)와 주의해야 할 세부 요인(Action Item)을 한눈에 파악하는 홈 화면입니다.

| 기능 구분 | 구현 목표 및 상세 내용 | 주요 UI/UX 스펙 | 비고 |
| :--- | :--- | :--- | :--- |
| **상태 대시보드** | **직관적인 위험도 시각화**<br>- 현재 관리 중인 질병의 위험도를 **원형 게이지(Circle Gauge)**로 표시.<br>- **질병 스와이프:** 좌우 스와이프로 다른 질병 상태 확인. | • **상태별 색상:**<br>🟢 **안전(0~30%):** Green<br>🟡 **주의(31~70%):** Yellow<br>🔴 **위험(71%~):** Red | 데이터 없을 시<br>`수집중 --%` 표시 |
| **날짜 전환** | **오늘/내일 상태 확인**<br>- 상단 탭(`오늘`/`내일`)을 통해 예측 시점 전환.<br>- 내일 확률은 야식 등 잔존 소화 시간 고려하여 계산. | • 탭 전환 시 게이지 및 하단 데이터 애니메이션 교체 | |
| **주요 위험 요인** | **행동 가이드 제공 (Top 3)**<br>- 현재 위험도를 높인 주범(태그/속성) 3가지를 카드 형태로 노출.<br>- **종합 상태와 별개로, 해당 요인의 기여도에 따라 경고 색상 표시.** | • **카드 UI:** 아이콘 + 텍스트 + 위험도(%)<br>• 클릭 시 해당 요인의 **상세 분석 페이지**로 이동 | |
| **기록 액션** | **빠른 기록 진입 (Floating)**<br>- 하단 `[+]` 버튼 클릭 시 **액션 시트(Action Sheet)** 호출.<br>- `[⚡ 아파요]` vs `[🍽️ 먹었어요]` 선택 분기. | • **아파요:** 즉시 기록 후 토스트 메시지<br>• **먹었어요:** 음식 기록 화면으로 이동 | |

## 3. 📝 기록하기 (Logging)
사용자의 입력 피로도를 최소화(Minimal Effort)하면서도, 분석에 필요한 핵심 데이터(사진, 태그, 시간)를 빠짐없이 수집하는 것이 목표입니다.

| 기능 구분 | 구현 목표 및 상세 내용 | 주요 UI/UX 스펙 | 비고 |
| :--- | :--- | :--- | :--- |
| **기록 진입** | **목적별 빠른 분기**<br>- 메인 `[+]` 버튼 클릭 시 액션 시트 노출.<br>- `[⚡ 아파요]` : 즉시 증상 기록.<br>- `[🍽️ 먹었어요]` : 음식 기록 화면 진입. | • **아파요:** 별도 화면 없이 토스트("기록 완료") 피드백<br>• **먹었어요:** Full Page 입력 폼 이동 | |
| **음식 기록** | **스마트한 입력 프로세스**<br>- **사진:** 갤러리/카메라 선택. (썸네일 리사이징, **WEBP 전용**)<br>- **메뉴명:** 텍스트 입력 시 **검색 API 기반 자동완성** 제공.<br>- **재료:** `[+ 추가]` 버튼을 통해 해시태그 형태로 입력.<br>- **식당명:** 자동완성 지원 (카테고리: RESTAURANT). | • **자동완성:** 실시간 검색 결과 (최소 2자, 최대 15자)<br>• **재료 칩:** 입력된 재료는 삭제 가능한 칩 형태로 나열<br>• **이미지:** WEBP 형식만 업로드 가능 | Rate Limit: 3회/분 (사용자당) |
| | **직관적인 속성 태그 (Chip Selection)**<br>- 맛, 온도, 상황 등 정해진 속성을 **버튼(Chip)**으로 빠르게 선택.<br>- 선택 시 즉시 시각적 피드백(반전/테두리).<br>- **태그 검색:** 해시태그 기반 검색 지원 (카테고리: INGREDIENT). | • **카테고리:** 맛/자극, 온도, 상황 등 그룹핑<br>• **다중 선택:** 여러 속성 동시 선택 가능<br>• **검색:** 태그 자동완성 및 추천 | |
| | **메타 데이터 자동화**<br>- **시간:** 현재 시간 Default (수정 가능).<br>- **식당:** 선택 입력 (자동완성 지원).<br>- **야식 판별:** 입력 시간(22시~) 기준 `#야식` 태그 자동 부여. | | |
| **증상 기록** | **초간편 원클릭 (One-Tap)**<br>- 복잡한 입력 없이 버튼 클릭 한 번으로 `발병 시점` 기록.<br>- **10초 멱등성 윈도우:** 중복 클릭 방지.<br>- **Throttle:** 10분 내 재기록 제한.<br>- **일일 제한:** 하루 10회 기록 제한.<br>- 실수 방지를 위한 `[실행 취소]` 기능 제공. | • **토스트:** "증상이 기록되었습니다. [실행 취소]"<br>• **제한 알림:** throttle/일일 제한 도달 시 안내 | Rate Limit: 10회/일 (사용자당) |

## 4. 📊 분석 및 조회 (Feed & Analysis)
사용자의 기록을 **시계열(Feed)**로 조회하고, 누적된 데이터를 다양한 관점(메뉴/태그/식당)에서 **시각화(Chart)**하여 인과관계를 파악합니다.

| 기능 구분 | 구현 목표 및 상세 내용 | 주요 UI/UX 스펙 | 비고 |
| :--- | :--- | :--- | :--- |
| **피드 (Tab 2)** | **타임라인 조회 (History)**<br>- 음식 및 증상 기록을 최신순 리스트로 조회.<br>- **오버레이 UI:** 음식 사진 위에 연관된 질병/증상 정보 표시.<br>- **검색 기능:** 피드 내용 검색 (메뉴, 식당, 재료).<br>- **최근 검색어:** 사용자별 검색 히스토리 관리. | • **카드 UI:** 사진 + 메뉴명 + 태그 + (증상 뱃지)<br>• **관리:** 더보기(...) 메뉴를 통해 수정/삭제 가능<br>• **검색창:** 자동완성 및 필터링 지원 | Rate Limit: 10회/분 (검색) |
| | **캘린더 필터링 (Calendar)**<br>- **버티컬 스크롤:** 월 경계를 넘어 자유롭게 탐색 가능.<br>- 날짜 선택 시 해당 일자의 기록만 리스트에 필터링. | • **Dot:** 발병일(🔴) / 기록일(🟢) 표시<br>• **헤더:** 스크롤 위치에 따라 년/월 타이틀 자동 변경 | |
| **분석 (Tab 4)** | **종합 대시보드 (Overview)**<br>- **위장 건강 점수:** 100점 만점 기준 점수와 도넛 차트.<br>- **핵심 요약:** "주로 [저녁]에 [매운맛] 때문에 아팠어요" 문구 제공. | • **토글:** `[위험/안심]` 모드 전환<br>• **점수:** 노란색(주의), 초록색(안심) 등 상태 컬러 적용 | |
| | **유형별 랭킹 (Detail Tabs)**<br>- **3가지 관점:** 음식 / 태그 / 식당 탭으로 분리.<br>- **Top 3:** 가장 위험한(또는 안전한) 요인을 게이지 바로 시각화.<br>- **급상승 트렌드:** 최근 2주간 위험도가 급증한 항목을 스파크라인(Sparkline) 차트로 경고. | • **리스트:** 4위부터는 심플한 리스트로 나열<br>• **차트:** 시간대별 발병 패턴(막대), 태그 유형 분석 등 | |
| **상세 분석** | **Drill-down Insight**<br>- 랭킹 항목 클릭 시 해당 요인의 **상세 리포트** 제공.<br>- **히어로 카드:** 위험도(%) 강조.<br>- **히스토리:** 섭취 이력 및 시간대별 패턴 분석. | • **구성:** 요약 카드 + 통계(횟수) + 시간대 차트 + 사진 기록 | |

## 5. ⚙️ 설정 및 마이페이지 (Settings)
사용자의 개인화 설정(알고리즘 변수)과 데이터 자산을 관리하는 제어 센터입니다.

| 기능 구분 | 구현 목표 및 상세 내용 | 주요 UI/UX 스펙 | 비고 |
| :--- | :--- | :--- | :--- |
| **마이 리포트** | **성취감 부여 (Gamification)**<br>- 메인 좌측 상단 프로필 클릭 시 **리포트 팝업** 노출.<br>- 연속 무증상(Streak), 골든 타임(식후 N시간), 질병 비중 확인. | • **시각화:** 7일간의 상태를 점(Dot)으로 표현한 스트릭<br>• **동기부여:** "5일째 속이 편안해요!" 등의 메시지 | |
| **계정 관리** | **프로필 수정**<br>- 닉네임 및 프로필 사진 변경 (이미지 크롭 지원).<br>- 비밀번호 변경 및 로그아웃. | • **탈퇴:** 신중한 결정을 위해 **경고 모달** 및 사유 선택 과정 포함 | |
| **건강 설정** | **알고리즘 튜닝**<br>- **관리 질병:** 내 질병 태그 추가/삭제.<br>- **소화 유효 시간:** 발병 확률 계산의 기준 시간(`Window`) 설정. | • **UI:** `18시간(추천)` 등 휠 피커(Wheel Picker)로 선택 | Default: 18h |
| **데이터 관리** | **입력 편의성 관리**<br>- **단어 관리:** 자동완성 목록에서 숨김 처리한 단어 조회/복구.<br>- **즐겨찾기:** 자주 쓰는 메뉴/식당 관리. | • **검색/리스트:** ㄱㄴㄷ 인덱스 스크롤 지원 | |
| **앱 정보** | **고객 지원**<br>- 공지사항 조회 및 문의하기.<br>- 이용약관/개인정보처리방침 확인. | [이용약관 주소](https://www.notion.so/WELOG-26-02-25-3129eca7188b8094aacad1f201beee97?source=copy_link) <br> [개인정보처리방침 주소](https://www.notion.so/WELOG-26-02-25-3129eca7188b80c8adeddbcae58ce09d?source=copy_link) | |
