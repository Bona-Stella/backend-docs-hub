# 🏥 WeLog (위로그) - V1.0 기능 명세서

> **WeLog**는 '위(Stomach)'와 '로그(Log)'를 합친 이름으로, 식습관 기록과 질병 발병 데이터를 분석하여  
> 오늘과 내일의 발병 확률을 예측해 주는 **위장 건강 관리 헬스케어 서비스**입니다.

---

## 1. 👤 회원가입 및 온보딩 (User Onboarding)
사용자가 서비스에 진입하여 데이터를 쌓을 준비를 하는 단계입니다.

| 기능 구분 | 상세 기능 | 사용자 경험 (User Flow) | 비고 |
| :--- | :--- | :--- | :--- |
| **회원가입** | 이메일 가입 | 이메일, 비밀번호, 닉네임 입력 → 가입 완료 | 이메일 인증 절차 간소화 (형식 체크만) |
| **로그인** | 이메일 로그인 | 이메일/비밀번호 입력 → 메인 화면 진입 | JWT 기반 자동 로그인 유지 |
| **초기 설정** | **질병 등록** | 가입 직후 또는 초기 진입 시 관리할 질병 등록<br>(예: 역류성 식도염, 과민성 대장 등) | 최소 1개 이상 등록 유도 |

## 2. 🏠 메인 대시보드 (Dashboard)
현재 나의 위장 상태 위험도를 직관적으로 파악하는 홈 화면입니다.

| 기능 구분 | 상세 기능 | 사용자 경험 (User Flow) | 비고 |
| :--- | :--- | :--- | :--- |
| **위험도 예측** | **오늘 발병 확률** | **"오늘 발병 확률 N%"** 문구와 원형 차트 표시.<br>확률이 높을수록 경고 색상(Red) 강조. | 초기 데이터 없을 시 0% 시작 |
| | **내일 발병 확률** | 사용자가 화면 스와이프/탭 시 내일 예측 확률 표시.<br>(야식 등 소화 시간 고려) | |
| **위험 요인** | **Top 3 태그** | 현재 확률을 높인 주원인 태그 3개 노출.<br>(예: 🌶️매운, ☕카페인, 🥛우유) | 클릭 시 상세 분석 페이지 이동 |
| **기록 버튼** | 플로팅 버튼 | 하단 [+] 버튼을 통해 **음식 기록** 또는 **증상 기록** 진입 | |

## 3. 📝 기록하기 (Logging)
WeLog의 핵심 기능입니다. 입력 피로도를 최소화하면서도 양질의 데이터를 수집하도록 설계되었습니다.

| 기능 구분 | 상세 기능 | 사용자 경험 (User Flow) | 비고 |
| :--- | :--- | :--- | :--- |
| **음식 기록** | **이름/사진** | 음식 이름(텍스트) 입력 + 사진 업로드(선택).<br>이름 입력 시 **최근 먹은 메뉴 자동완성** 제공. | 사진은 서버 리사이징 저장 |
| | **재료 입력** | 주요 재료는 텍스트(해시태그)로 직접 입력.<br>(예: #돼지고기 #면 #두부) | |
| | **상태 선택**<br>**(핵심 UI)** | **버튼(Chip) 선택 방식**으로 쉽고 빠르게 입력.<br>• **맛(속성):** 🌶️매운, 🍔기름진, 🧂짠, 🍋신<br>• **온도:** 🧊차가운, 🔥뜨거운<br>• **식감:** 🍜밀가루, 🍤튀김, 🍣날것<br>• **상황:** 😵과식, ☕공복, 🍺음주, ⏱️급하게 | **재료 외 태그는 버튼으로 제공** |
| | **기타 정보** | 식당 이름(텍스트), 섭취 시간(Default: 현재). | **#야식** 태그는 시간(22시~) 기준 자동 저장 |
| **증상 기록** | **발병 체크** | "지금 아픈가요?" 버튼 클릭 → 질병 선택 → 저장. | 날짜/시간 자동 기록 |

## 4. 📊 분석 및 조회 (Analysis)
누적된 데이터를 기반으로 인과관계를 파악하는 페이지입니다.

| 기능 구분 | 상세 기능 | 사용자 경험 (User Flow) | 비고 |
| :--- | :--- | :--- | :--- |
| **피드(Feed)** | 타임라인 | 내가 기록한 음식/증상을 최신순 리스트로 조회.<br>각 기록별 위험도 점수 표시. | |
| **캘린더** | 발병일 확인 | 달력에 발병한 날짜가 🔴 표시됨.<br>날짜 클릭 시 해당 일자의 섭취/증상 기록 필터링. | |
| **차트 분석** | **유형별 위험도** | 3가지 관점의 독립적인 위험 확률(%) 제공<br>1️⃣ **메뉴별:** "이 메뉴 먹었을 때 얼마나 아팠나?"<br>2️⃣ **태그별:** "이 재료/속성일 때 얼마나 아팠나?"<br>3️⃣ **식당별:** "이 식당 갔을 때 얼마나 아팠나?" | |
| **수정/관리** | **계산 제외** | 특정 기록(예: 폭음)을 분석 로직에서 제외하는 기능. | 아웃라이어(이상치) 관리 |

## 5. ⚙️ 설정 (Settings)
개인화 설정 및 계정 관리입니다.

| 기능 구분 | 상세 기능 | 사용자 경험 (User Flow) | 비고 |
| :--- | :--- | :--- | :--- |

| **데이터** | 질병/태그 관리 | 등록된 질병 삭제/추가. | |
| **계정** | 프로필 관리 | 닉네임 변경, 프로필 사진 변경, 로그아웃, 탈퇴. | |
