## 📌 프로젝트 개요 (WeLog)
**WeLog(위로그)**는 '위(Stomach)'와 '로그(Log)'를 합친 이름으로, 식습관 기록과 질병 발병 데이터를 분석하여 오늘과 내일의 위장 질환 발병 확률을 예측해 주는 헬스케어 서비스입니다.

### [2026-01-14] v0.4.0 - 분석(Analysis) 탭 전체 디자인 완료
- **작업 내용:**
  - **분석 탭 하위 화면(Sub-tabs) 디자인 확정:**
    - **종합(Overview) 탭:** 
      - 건강 점수(Score) 도넛 차트 및 '위험/안심' 모드에 따른 동적 멘트(Insight Message) UI 구현.
      - 헤더 우측에 텍스트 토글을 배치하여 전체 대시보드의 톤을 제어하는 UX 확립.
    - **음식(Menu) 탭:**
      - **Top 3 랭킹:** 불필요한 뱃지/해시태그를 제거하고 메뉴명을 강조한 심플한 리스트 디자인 적용.
      - **급상승 차트:** 최근 위험도 변화를 보여주는 스파크라인(Sparkline) 카드에 데이터 포인트(Dot)와 증감 수치를 명시하여 가독성 강화.
      - **상세 리스트:** 메뉴별 '기록/발병 횟수'를 텍스트 라벨로 표기하여 정보 밀도 최적화.
    - **태그(Tag) / 식당(Restaurant) 탭:**
      - 음식 탭의 레이아웃 시스템을 계승하여 일관성 유지 (카테고리별 아이콘 및 랭킹 구조 동일 적용).
  - **상세 분석(Detail View) 화면 고도화:**
    - **히어로 카드(Hero Card):** 대상의 위험도(%)를 강조하는 상단 카드와 가로 꽉 찬 게이지 바 적용.
    - **통계 요약:** '총 기록 / 발병 횟수 / 최근 섭취' 정보를 3분할 텍스트 레이아웃으로 정돈하여 시각적 인지 부하 감소.
- **비고:**
    - **디자인 시스템 통일:** 모든 차트와 리스트에 브랜드 컬러(Neon Red/Green/Yellow)를 위계에 맞게 적용하여 '위험 단계'를 직관적으로 전달.

### [2026-01-13] v0.3.7 - 분석 대시보드 설계 및 캘린더 구현
- **작업 내용:**

    - **레이아웃 표준화:** '헤더(기간/탭) → 컨트롤(위험/안심 토글) → 데이터(차트/리스트)'로 이어지는 공통 UI 구조 수립.
    - **네비게이션:** 상단 탭(종합/음식/태그/식당) 간의 일관된 이동 경험 및 스위치 위치 통일.

    - **종합 요약 카드:** 위장 건강 점수(Score)를 시각화한 **도넛 차트(Donut Chart)**와 핵심 원인(시간+원인) 요약 문구 배치.
    - **상세 분석(Detail View) 컨셉:** 개별 항목(예: 마라탕)의 위험도를 직관적으로 보여주는 **히어로 카드(Hero Card)** 및 3분할 통계(기록/발병/최근) 레이아웃 적용.
  - **분석 캘린더(Calendar) UI/UX 구현:**
    - **버티컬 스크롤(Vertical Scroll):** 월(Month) 경계를 끊김 없이 넘나들며 기간을 선택할 수 있는 상하 스크롤 방식 채택.
    - **사용성 개선:** 매월 1일 날짜 위에 'N월' 텍스트를 표기하고, 스크롤 비중에 따라 상단 년/월 타이틀이 변경되는 스마트 헤더 로직 적용.
- **비고:**
    - **토글 인터랙션:** 카드 타이틀 우측에 '위험/안심' 텍스트 토글을 배치하여, 모드 전환 시 차트 데이터와 멘트가 동적으로 변경되도록 설계.
